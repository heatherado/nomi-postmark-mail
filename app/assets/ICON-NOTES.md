# Lamplit Mail icon

lamplit-mail-source.png is the original generated transparent artwork; lamplit-mail-v1.ico is its multi-resolution Windows container, including 16, 20, 24, 32, 40, 48, 64, 96, 128 and 256 pixel sizes. The source artwork is preserved without repainting. Conversion/resampling only was used for ICO packaging.

Generated using the built-in image generation tool. No API key or CLI fallback was used. The app and shortcuts reference this project-local ICO, not a file in the generation cache. No extra Python package is needed to use it. Pillow was used only during development to convert and validate the ICO.

Final prompt:

Use case: stylized-concept. Asset type: finished Windows desktop/taskbar application icon for Nomi Postmark Mail, Lamplit Desk. Create ONE original polished illustrated enamel-style app badge, square composition, centered. Subject: a sturdy warm brass postal lantern whose glowing cream light chamber contains one clear simple sealed envelope silhouette. Midnight-blue rounded-square backplate (#101d2b to #172838), warm brass (#e3bc7d), parchment cream; one small four-point star near the lantern. Cozy storybook nighttime post-office mood, restrained rich enamel and softly burnished metal, clean bold silhouette and thick simplified forms, very high clarity at 16/32 pixels. The lantern/envelope is the dominant large mark, fills about 75% of badge. Badge fills nearly the whole square with about 5% exterior breathing room. Genuinely transparent outside the rounded-square badge; preserve clean alpha. No writing, letters, initials, numerals, watermark, labels, photoreal scene, thin filigree, extra props, mockup presentation, icon sheet or multiple variants. Front-facing, balanced, softly dimensional with modest glow only inside the badge.
